# Recover Desk

Run one bounded inspection of the **existing** installation. Read `agent-desk doctor`, a full snapshot and its truncation flags, `agent-desk dispatch status`, the configured state directory, and the actual supervised `agent-desk dispatch watch` process. Verify the local page at `127.0.0.1` if the user uses it. A saved configuration or stale status file does not prove a process is running.

Restart a missing local web view or observer only from its existing verified command and only if delivery was enabled. Preserve global pause, quiet hours, wake budgets, the configured dispatcher thread, and all pending events. Inspect the exact task and queue receipt before declaring a reserved or uncertain wake lost. Do not replay it, clear it, create a replacement task, or re-enroll another agent from an expired connection. A resumed agent may refresh **its own** consumer under its existing authorization.

Report the verified healthy pieces, anything restored, and the exact original conversation the user must reopen if a provider's session watcher cannot be resumed programmatically. Queued, accepted, and completed work are distinct. Recovery grants no merge, deployment, external send, or authority expansion.
